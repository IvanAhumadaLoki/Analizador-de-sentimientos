# Analizador de Sentimientos Automatizado 🤖📊

Este proyecto analiza comentarios de clientes en español utilizando Inteligencia Artificial, genera estadísticas visuales y exporta un reporte profesional en PDF.

## 🚀 Funcionalidades
- **NLP con Pysentimiento:** Clasificación precisa de sentimientos (Positivo, Negativo, Neutral).
- **Visualización de Datos:** Gráficos generados con Seaborn/Matplotlib.
- **Reportes Automáticos:** Generación de PDF con resultados ejecutivos.

## 🛠️ Instalación
1. Clona el repositorio.
2. Crea un entorno virtual: `python -m venv venv`.
3. Activa el entorno: `.\venv\Scripts\activate`.
4. Instala dependencias: `pip install -r requirements.txt`.

## 📈 Uso
1. Genera datos de prueba: `python generar_datos.py`
2. Ejecuta el análisis: `python main.py`
